Generated by `python -m agentic_rag.kvpaths.run` then `kvpaths.report`. Greedy decoding, one H20. `budget` = fraction of *corpus* KV kept per layer and KV head (the system instruction and end-of-turn tokens are always kept and not counted). `gap` = accuracy(lookup) − accuracy(join) over paired questions with the same evidence and gold, with a 95% bootstrap interval that resamples whole supply links. `DiD` = that gap minus the same pairs' gap under the full KV (the join cost added by compression). Accuracy is lenient (a final `答案：X` counts when the JSON line is missing); `fmt` = answers right under lenient but wrong under strict JSON parsing, `strict gap` = the gap under strict parsing. `oracle` keeps only the gold documents and reads the question over them; `oracle_aware` keeps the same documents but, like `query`/`join`, keeps the question KV computed over the full context. Wrong answers: `null` = said the evidence is missing, `near` = a number within 10% of gold (right document, corrupted digits or adjacent field), `far` = anything else.
